# Feedback

We welcome feedback, bug reports, and suggestions for uhu.

## How to Reach Us

- **Telegram:** [@MartiAi_Feedback_bot](https://t.me/MartiAi_Feedback_bot) — send messages directly
- **GitHub Issues:** [uhu/issues](https://github.com/andreisminsk/uhu/issues) — open a new issue

## What to Include

When reporting a bug or issue, please include:

- The command you ran
- The full error message or unexpected behavior
- Your environment: OS, Python version, Ollama version, API used, LLM
